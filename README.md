HOMEBREW TAP
---

This tap provides casks to install the following CLI's:

| Cask | Link |
| --- | --- |
| Firn | https://github.com/rahulkj/firn |
| Go-certs | https://github.com/rahulkj/go-certs |
| Orchard | https://github.com/rahulkj/orchard |
| Setup GH Secrets | https://github.com/rahulkj/setup-gh-secrets |
| Shave | https://github.com/rahulkj/shave |

Install any cask with:

```bash
brew install --cask rahulkj/tap/<cask>
```
